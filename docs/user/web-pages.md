# Web pages

Keep sites such as DeepSeek and ChatGPT in T3 Code and use them without opening
your browser each time. Web pages are available only in the desktop app.

## Get started

Choose **Web pages** in the project rail, then **Add**. Enter a website address
and an optional name. If you leave the name blank, T3 Code uses the domain.
Select a saved page to open it. Search the list by name or domain.

Use a page's menu to edit or delete it. Deleting an entry keeps the site's
login state. Choose a project or **All projects** to return to your previous
code conversation.

## Sign in

Entries for the same website share a login. These logins are separate from
the built-in browser in threads. AI agents cannot see or operate your saved
web pages.

To sign out, use the website's own sign-out option.

## Pause a page

Choose **Pause (release resources)** from a running page's menu to unload it.
The saved entry remains, but unsent content is lost. Choose **Load** to open
the paused page again.

## Follow links

Ordinary links open in the current entry. Links that request a new tab open
in your system browser. Sign-in popups open inside the app. To move the current
page to your browser, choose **Open in system browser** in the page toolbar.

Some websites, including some Google account sign-in flows, may reject embedded
browsers. Use your system browser when a site does not support signing in here.
